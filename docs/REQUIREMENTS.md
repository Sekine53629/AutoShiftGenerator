## 1. 目的

薬局のシフト表を Google スプレッドシート上で自動作成する。
Excel VBA 版 `Auto_Shift_Generator` の置き換え。

**できあがるシフト表の見た目と中身は、いまの Excel 版と同じ。**
違うのは作る手段だけ。

## 2. 完成形

### 2.1 Excel は経路に入らない

日々の運用で Excel を開くことはない。スプレッドシートだけで完結する。

移行のときに一度だけ実物を参照することはありうるが、**恒常的な依存にはしない**。
現在ある `tools/ExportFormatProfile.bas`（Excel から書式を書き出す VBA）は
この方針に照らすと位置づけが下がる。★1

### 2.2 出力

利用者の言葉では「新しいシートを生成する」と「完全に新しいブックと PDF を生成する」の
両方が挙がった。技術的には**両立できるが、役割が違う**。★2

| | 中身 | 用途 |
|---|---|---|
| 作業用 | 1つのブックに月ごとのシート | 希望休を入れる・自動作成を回す・直す |
| 配布用 | 値と書式を固めた別ブック + PDF | 印刷して貼る・スタッフに渡す |

**作業用を別ブックに分けられない理由がある。**
集計の数式が `自動作成設定` シート（区分・必要出勤数）と `祝日マスタ` を参照している。
月ごとに別ブックにすると、これらが `IMPORTRANGE` になり、
承認が要るうえ再計算が遅く、壊れやすい。

そのため **作業は1つのブックの中で行い、固まったら別ブックへ書き出す**のが素直。
これは VBA 版の `ShiftExport` が「値と書式を固めた別ブックを作って印刷する」と
していたのと同じ発想。

### 2.3 月次の流れ（想定）

```
1. 新しい月のシートを作る          … シートを生成（書式・数式込み）
2. 希望休・有休を入れる            … 手入力
3. 自動作成を実行                  … 空白を埋める
4. レポートを見て手直し            … 過不足・連勤・ノルマ未達を確認
5. 配布用に書き出す                … 別ブック + PDF          ★2
```

## 3. 書式をどう決めるか ★1

「スプレッドシートのフォーマット書式に入れる形」という言葉の解釈が2通りある。

| | 内容 | 影響 |
|---|---|---|
| **A. Sheets 側で定義し直す** | 見本となる書式を Sheets 上で1つ作り込み、それを正とする | `FormatProfile` の取り込み機能と Excel エクスポータは不要。既定値を作り込むだけ |
| **B. 実物から測って持ってくる** | いまの Excel の見た目を数値として持ち、再現する | いま作ったものが活きる。ただし Excel への一度きりの依存が残る |

**私の見立ては A。** 恒常的に Excel を開かないなら、書式の正は Sheets 側にあるべきで、
「Excel から測る」機構は移行が済んだ時点で死ぬ。
既定値（`Config.gs` の `FORMAT_DEFAULT`）を実物に合わせて詰めれば足りる。

A を採る場合、次のものは役目を終える。

- `tools/ExportFormatProfile.bas`（Excel エクスポータ）
- `FormatProfile.captureFormatProfile` / `importFormatProfileJson`（取り込み）
- `ImportProfileView.html`

**書式プロファイルの仕組み自体（役割ごとに色や高さを持ち、生成時に当てる）は
どちらでも残る。**変わるのは「値をどこから得るか」だけ。

## 5. 配置アルゴリズムの厳密さ（確定）

**VBA 版と同じ出力**。仕様書 §4 と §9 フェーズ3 のとおり。

これは次を意味する。

- 検証のために **VBA 版で実データ（匿名化）を流し、`mPlan` / `mSymb` を吸い出す作業**が要る
- 移植中にアルゴリズムを「改善」しない。不満があっても移植後に別の変更として行う
- `Engine.gs` は `SpreadsheetApp` を呼ばない純粋関数のままにする

**すでに1か所、VBA 版と結果が変わる変更を入れている。**
`WORK_SYM_PREFIX_MATCH`（派遣行の「▲＋氏名」を出勤として数える）。
検証のときは `false` に戻して比べること。
`CB_CHAIN_MAX_PASS`（玉突きの打ち切り）も VBA 版に無い制限。
