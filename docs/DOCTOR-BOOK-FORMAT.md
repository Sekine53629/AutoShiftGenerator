# 医師シフトのブック（送られてくる .xlsx）

毎月 `◯年◯月医師シフト.xlsx` が送られてくる。これを読んで医師名欄を埋める
（`prototype/ShiftGrid.html` の「医師シフトを取り込む」）。

**氏名は実在の医師のものなので、このリポジトリには入れない。**
見本は `prototype/samples/` に置くが `.gitignore` 済み。以下の例は架空の表記。

---

## 1. 形

`Sheet1` が暦。`Sheet2` に医師の一覧（あることも無いこともある）。

```
      A          B          C          D          E          F          G
  1  2026-09-01                                                              ← 使われていない
  2  2026-10-01                                                  令和8年
  3
  4  日         月         火         水         木         金         土     ← 目印にする行
  5  (空)       (空)       (空)       (空)       10/1       10/2       10/3   ← 日付の行
  6
  7
  8  式         式         式         式         山田 太郎   山田 太郎   山田 太郎
  9  式         式         式         式         佐藤 花子   佐藤 花子   鈴木 次郎
 10  …
 13  10/4       10/5       10/6       10/7       10/8       10/9       10/10  ← 次の週
```

- 週の塊は8行ごと。ただし**この間隔に頼らない**（§3）
- 日付は Excel の通し番号。基準は 1899-12-30

## 2. 名前は式に埋まっている

```
  =IF(A5="","","山田 太郎")
```

「この列に日付があれば、この医師が出る」という書き方。**曜日ごとの定番**を
式で持ち、その月だけの例外は文字列で直接書いてある。

取り込みは**式の中の名前を先に読む**。計算結果（キャッシュ）だけを見ると、
再計算せずに保存されたブックで空になる。

## 3. 決め打ちしない

実物には次のものが入っていた。どれも「翌月のファイルで静かに壊れる」たぐい。

| 見たもの | 取り込み側の対処 |
|---|---|
| **A1 に前の月の日付**（2026-09-01） | A1 はどの式からも参照されていない。**番地を名指しして読まない** |
| A2 が基準（`$A$2`） | これも読まない。**年月は日付の行から多数決で決める** |
| **下のほうに別の月の暦**（1月分・32セル） | 曜日の見出し行を全部探し、**いちばん上の塊だけ**を読む |

3つ目は実害が出た。全部読むと日にちだけで突き合わせるので、下の月が上の月を
上書きし、10/4 が3人から5人に化けていた。

### 目印は曜日の見出し行

`日 月 火 水 木 金 土` が5つ以上そろう行を探す。その行より上（A1・A2・元号）は
見ない。次の見出し行が現れたら、そこで打ち切る。

## 4. 取り込みでやること

1. zip をほどく（`DecompressionStream('deflate-raw')`。ライブラリは使わない）
2. 曜日の見出し行 → いちばん上の暦 → 日付の行 → その下の名前
3. 年月を日付から決め、画面をその月に合わせる
4. 医師マスタに無い名前を**その場で登録する**。登録した名前は結果に並べて出す
5. **その月の医師名欄をいったん消してから**入れる（減った日に前の名前が残らないよう）

### シフト表に入れるのは姓だけ

医師欄の列は 26px しかない。フルネームは入らない（実測で5文字＝34px）。
**マスタの略称（＝姓）をセルに入れる。** 実物のシフト表も短い表記を使っている。

```
  ブック         マスタ                      シフト表のセル
  秋山 貴由  →  氏名 秋山 貴由 / 略称 秋山  →  秋山
```

略称は取り込みのときに姓から作る。**同じ姓が既にいたら、名の1文字目を添える。**

```
  秋山 貴由                    → 秋山
  西本 紀之（西本が既にいる）   → 西本(紀)
```

**括弧は半角。** 全角にすると2文字ぶんの幅を取り、列に収まらない。
それでもぶつかるとき（同姓かつ同じ頭文字）だけ数字を足す。
社員マスタにも同じ規則で略称の欄がある（マスタごとに見る。社員と医師で
同じ姓がいても構わない）。**あとから直せる。**

幅の実測（26px の列）:

| 略称 | 文字幅 | 字の大きさ | |
|---|---|---|---|
| 秋山 | 16.0px | 8.25px | ○ |
| 長谷川 | 24.0px | 8.25px | ○ |
| 西本(紀) | 21.4px | 6.19px | ○ |
| 長谷川(一) | 26.5px | 6px（下限） | 端が 0.5px 切れる |

3文字の姓に名を添えると、下限まで縮めても入りきらない。
その場合は医師マスタで略称を短く直すこと。

登録は黙ってやらない。「医師マスタに 9 名を新しく登録しました: …」と結果に出す。

控えは取り込みの直前に取るので、`← 戻す` で元に戻せる。

## 5. まだ見ていないもの

- 医師名欄の行数（既定6）を超える日。報せるだけで、行数は自動で増やさない
- `Sheet2` の一覧と `Sheet1` の名前が食い違う場合
- 様式が変わったとき。§3 の「決め打ちしない」で吸収できる範囲を超えたら作り直す
