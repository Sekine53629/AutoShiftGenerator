# 出力フォーマット（実物の計測）

PDF・xlsx の出力を実物に寄せるための計測記録。対象は R8.8月のブック。
Excel も VBA も使わず、`.xlsx` の中の XML を直接読んだ（`xl/styles.xml`,
`xl/worksheets/sheet1.xml`, `xl/theme/theme1.xml`）。

Google スプレッドシートへ取り込んだあとを測ると条件付き書式などが落ちるので、
**原本の XML を読むのが正しい。** `tools/ExportFormatProfile.bas`（VBA）も
同じ目的の道具だが、Excel を開く必要がある。XML 直読みなら要らない。

---

## 1. 列幅（文字数単位）

| 列 | 幅 | 用途 |
|---|---|---|
| A | 12.40 | 氏名 |
| B〜AG | 5.50 | 日付（32列） |
| AH〜AK | 6.60 | 集計（**4列**） |
| AL 以降 | 9（既定） | 未使用 |

**日付列は B〜AG の32列を常に確保している。** 31日の月でも AG が余り、
`#d0cece`（灰）で潰してある。月の日数に足りない列を灰色にする作り。

集計列は **4列**。仕様書 §5.4 は6列としているが、実物は4列
（`docs/REAL-SHEET-FINDINGS.md` に既出）。

## 4. 色

`xl/theme/theme1.xml` を解決した実値。

| 色 | 使いどころ |
|---|---|
| `#bdd7ee` | **土曜**（accent5 の tint 0.6） |
| `#ff6d6d` | **日曜と祝日**（同じ色） |
| `#d0cece` | **「ここは入力しない」の印**（下記3用途） |
| `#a9d18e` | 薬品発注担当の印（本文セル） |
| `#ffff00` | 備品発注日の印 |
| `#ff0000` | 強調 |

**祝日に専用の色は無い。日曜と同じ `#ff6d6d`。**
条件付き書式は使っておらず、すべて直接塗ってある。

### 灰色 `#d0cece` の3つの用途

同じ灰色が、意味の違う3か所に使われている。共通するのは
**「ここは入力しない／できない」** という意味。

1. **月の日数に足りない余り列**
   日付列は B〜AG の32列を常に確保するので、31日の月では AG が余る。
2. **出られない曜日**（個人ごと）
   R8.8月では、A列に `(月火金土18時)` と書かれた人の **日・水・木** が
   灰色で潰されていた。31日中13日。`availDow` の視覚表現にあたる。
3. **在籍していない期間**（行まるごと）
   同じ月に、31日すべてが灰色の行が1つあった。退職・休職で行だけ残っている形。

2 は「空欄」と「そもそも出られない」を見分けるために要る。プロトタイプは
`availDow` を配置には使っていたが画面に出しておらず、空欄と区別が付かなかった。
実物に合わせて灰色にした（`naDay_()`。押せなくはしない —
管理者が事情を承知で入れることはあり、入れればルール違反として表の下に出る）。

3 は扱いが違う。プロトタイプは `inService` で**行ごと消す**。実物は行を残して灰色にする。
月の途中で入退社した場合にどちらが読みやすいかは要判断。

  A18:A19  派遣欄
  A32:C32  凡例
  A33:C33  凡例
  A34:C34  凡例

## 6. 印刷設定

| 項目 | 値 |
|---|---|
| 向き | 横（landscape） |
| 用紙 | A4（paperSize 9） |
| 倍率 | **61%**（「幅に合わせる」ではなく固定倍率） |
| 余白 上下 | 0.748 inch（1.9 cm） |
| 余白 左 | 0.236 inch（0.6 cm） |
| 余白 右 | **0** |
| ヘッダ・フッタ | 0.315 inch（0.8 cm） |

右余白が 0。横1枚に収めるための詰め方。

## 7. プロトタイプとの差

| | 実物 | プロトタイプ | 備考 |
|---|---|---|---|
| 土曜 | `#bdd7ee` | `#b8c6da` | 近いが別の色 |
| 日曜 | `#ff6d6d` | `#e8927c` | 実物のほうが鮮やか |
| 祝日 | `#ff6d6d`（日曜と同じ） | `#ffd966` | **実物は祝日を区別しない** |
| 集計列 | 4列 | 6列 | 仕様書は6列 |

プロトタイプの3色は最初の指示で指定されたもの。**実物と違うのは承知のうえの選択か、
実物に合わせるかは要判断。** 祝日を日曜と同じ色にすると「その日が祝日だから休みが
増える」ことが表から読み取れなくなるので、区別する側にも理はある。

## 8. まだ測っていないもの

- 罫線（太さ・色・どこに引くか）
- 表示形式（日付セルの numFmt）
- 8月以外の月との差（様式が3回変わっているので、月による違いがある可能性）
